Experimenting with Singer’s 1978 “Introduction to DECsystem-10 Assembler Language Programming”. Here's the [pdf within the project](msc/dec10-assembler-singer.pdf). Page 4, creating a test file. Note that $ is the TOPS-10 echo for the escape key. Where you see \$, hit escape.

    .make test
    *ihello world$ex$$
    .type test
